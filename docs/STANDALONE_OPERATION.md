# Standalone operation

ThothScript is a local desktop editor. Opening, editing, searching, replacing, backing up, recovering, printing, and exporting files require no Groundstate account, Admin Center, cloud service, or organization directory.

Workspace files remain owned and controlled by the user. ThothScript does not upload documents or require hosted storage.

If collaboration or settings synchronization is added later, it must be optional and provider-neutral. Local editing, backup-before-replace behavior, recovery data, and file export must continue to work when disconnected.
